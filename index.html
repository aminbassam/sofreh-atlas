About the recipes · درباره‌ی دستورها

Home-style versions written for a family kitchen. Every village and family cooks these a little differently; treat quantities as a starting point. دستورها خانگی هستند و هر شهر و خانواده آن‌ها را کمی متفاوت می‌پزد.

Pictures · تصویرها

Each dish is painted in code on a Persian-tile plate; use “Real photos” on any recipe to see photographs. Ingredient images: Microsoft Fluent Emoji (MIT). Province shapes: Natural Earth.
